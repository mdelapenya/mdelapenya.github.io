## Github CLI Combine PRs

Es una extensión de GitHub CLI que combina varias PRs en una. Está pensada para repositorios que reciben muchas PRs que se pueden fusionar a la vez, como las PRs triviales de Dependabot que suben la versión de una dependencia.

- Repositorio de Github: [gh-combine-prs](https://github.com/mdelapenya/gh-combine-prs)
